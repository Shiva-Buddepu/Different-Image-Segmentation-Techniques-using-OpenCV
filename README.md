#  Different-Image-Segmentation-Techniques-using-OpenCV

This project demonstrates multiple **Image Segmentation techniques** using OpenCV in Python.  
It focuses on implementing and comparing **Edge-Based** and **Region-Based** segmentation methods.

---

##  Project Overview

Image Segmentation is a key Computer Vision technique used to divide images into meaningful regions.

In this project, the following approaches are implemented:

- Edge-Based Segmentation
- Region-Based Segmentation

The implementation is done using **OpenCV**, **NumPy**, and **Matplotlib** in Jupyter Notebooks.


---

##  Techniques Implemented

### 1️⃣ Edge-Based Segmentation

Implemented in:
`Edge base Segmentation.ipynb`

Methods include:

- Gaussian Blur (Noise Removal)
- Canny Edge Detection
- Sobel Operator
- Contour Detection

These methods detect boundaries by identifying sharp intensity changes in the image.

---

### 2️⃣ Region-Based Segmentation

Implemented in:
`Region Based Segmentation.ipynb`

Methods include:

- Thresholding
- Watershed Algorithm
- Region extraction techniques

These methods segment images based on similarity in pixel intensity or region connectivity.

---

##  Workflow

1. Load Image
2. Convert to Grayscale
3. Apply Preprocessing (Gaussian Blur)
4. Apply Segmentation Technique
5. Visualize Output
